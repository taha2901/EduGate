# 🏫 EduGate (School Management)

A cross-platform **School Management System** (Mobile & Desktop) built with Flutter.  
Designed for administrators and accountants to manage students, staff, payments, and school inventory efficiently.  

> **Note:** This is currently completed as a **full UI/UX design**. Database integration will be added in the next phase.

## 📌 Features

- 👨‍🎓 Student Management
  - Add new students
  - Track enrollment
  - Attendance management
- 💰 Payment & Financial Reports
  - Payment tracking
  - Financial insights
- 👩‍🏫 Staff Management
  - Teachers, admin, maintenance
- 🏢 School Inventory
  - Devices, desks, chairs, stationery
- 📢 Announcements & Notifications
- 📊 Full operational control over school system
- 🖥️ Desktop & Mobile support
- 🌙 Light & Dark Mode (UI/UX ready)
